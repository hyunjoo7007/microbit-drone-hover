작은 기울기로 시작하는 게임

마이크로비트 V1·V2에서 사용할 수 있습니다. 실제 장치 연결은 PC Chrome·Edge를 이용하세요. 휴대폰에서는 시연 모드를 체험할 수 있습니다.

1인 USB 직접 연결

플레이어 A 1대 → USB → PC
참가 인원은 ‘1인 연습’으로 선택하세요.

2인 무선 대결

플레이어 2대 → 무선 → 수신기 1대 → USB → PC
2인 대결은 총 3대가 필요합니다.

  1. MakeCode 열기 → 새 프로젝트 → JavaScript를 선택하세요.
  2. 아래 플레이어 코드를 붙여넣고 각 장치에 다운로드하세요. 무선 참가자 ID는 A·B로 서로 다르게 설정하세요.
  3. 무선 대결은 별도 수신기에 수신기 코드를 다운로드하세요. 모든 장치는 무선 그룹 43을 사용합니다. 기존 흔들기 게임 코드와 다릅니다.
  4. 직접 연결이면 플레이어를, 무선 연결이면 수신기를 USB 데이터 케이블로 PC에 연결하세요. MakeCode의 시리얼 창은 닫아주세요.
  5. ‘마이크로비트 연결’을 누르고 USB 포트를 선택하세요. 각 참가자 카드에 ‘수신 중’이 표시되어야 게임을 시작할 수 있습니다.
  6. LED 화면이 위를 향하도록 평평하게 들고 게임을 시작하세요. 드론 중심이 목표 원 안에 들어가면 연속 유지 시간을 기록합니다. 실제 기울기 허용각 게임과 달리 바람을 상쇄하도록 기울여야 합니다. 드론 위치는 공통 바람과 센서 기울기 입력을 합쳐 계산합니다. 화면 오른쪽으로 기울이면 오른쪽, 앞뒤 기울기는 화면 상하로 반영됩니다. 좌표 (0,0)이 목표입니다.
